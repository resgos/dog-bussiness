# 🐾 Лапка помощи

> Городское сообщество собачников Москвы для оперативного поиска потерявшихся собак.
> **Каждый хвост на учёт.**

«Лапка помощи» объединяет владельцев собак в единую городскую стаю взаимопомощи:
SOS-оповещение соседей за 60 секунд, карта поиска, районное комьюнити, цифровой
паспорт питомца с QR-кодом и магазин адресников ручной работы. Маскот — корги
Шуня — сопровождает пользователя во всех ключевых сценариях, в том числе как
интерактивный плавающий помощник.

Проект разрабатывается по ТЗ «Лапка помощи» (адаптивный веб-сайт + мобильное
приложение iOS/Android).

## 🧰 Технологический стек

| Слой | Технология | Зачем |
|------|------------|-------|
| Фреймворк | **Next.js 15 (App Router) + TypeScript** | SSR публичных паспортов по QR и SEO, файловый роутинг 1:1 с картой сайта, API-роуты как бэкенд |
| База данных | **Prisma + SQLite** (локально) | питомцы, владельцы, события «найдено»; Postgres-ready (сменить provider) |
| Стили | **Tailwind CSS v4** | дизайн-токены палитры прямо в CSS (`@theme`) |
| Анимации | **Framer Motion** | живая Шуня, появления секций, count-up, компаньон |
| Иконки / QR | **lucide-react** · **qrcode.react** | иконки и QR-код паспорта |
| Тесты | **Vitest** (node-окружение) | юнит-тесты логики |
| Шрифты | **Comfortaa** (заголовки) + **Nunito** (текст) | округлые, тёплые, с поддержкой кириллицы |

> **Пины под окружение.** На машине Node **20.8.1**: **Next.js 15.5.19** (Next 16 ≥ 20.9),
> **Vitest 2.1.9** (Vitest 3/rolldown ≥ 20.12), **Prisma 5.22**. Тесты — в node-окружении
> (jsdom несовместим). Обновишь Node до 22 LTS — поднимем версии.

### Интеграции (по дорожной карте)
- **PostgreSQL** в проде — сейчас локально SQLite; схема переносится сменой provider.
- **Яндекс.Карты API** — карта поиска и точки прогулок.
- **Telegram-бот** — дублирование SOS в районные чаты.
- **Нативное приложение** — Expo/React Native (сейчас веб — устанавливаемая PWA).

## 🚀 Запуск

```bash
npm install
cp .env.example .env      # DATABASE_URL для SQLite
npm run db:migrate        # создать БД + сгенерировать Prisma Client
npm run db:seed           # демо-данные (питомцы + события «найдено»)
npm run dev               # http://localhost:3000 (или ближайший свободный порт)
```

Прочее:

```bash
npm run build    # production-сборка
npm run lint     # ESLint
npm test         # Vitest — юнит-тесты логики
npm run db:studio # Prisma Studio — просмотр БД
```

Приложение устанавливается как **PWA** (manifest + иконки) на домашний экран iOS/Android.

## ⚠️ Заметки

- Локально — **SQLite** (`prisma/dev.db`, в git не коммитится; миграции — да). Для прода
  сменить `provider` на `postgresql` и `DATABASE_URL`. Массивы (приметы, маршруты,
  характер) хранятся как JSON-строки — SQLite не поддерживает scalar lists.
- Авторизация пока без сессий: контакты питомца берутся из формы мастера, не из профиля.
- Счётчик «найдено сегодня» считает события `FoundEvent` за сутки; их создаст режим SOS
  (Этап 4), сейчас засеяны демо-данными.
- `npm audit` — 2 умеренных предупреждения от транзитивного `postcss` (build-time).
