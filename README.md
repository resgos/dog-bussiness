# 🐾 Лапка помощи

> Городское сообщество собачников Москвы для оперативного поиска потерявшихся собак.
> **Каждый хвост на учёт.**

«Лапка помощи» объединяет владельцев собак в единую городскую стаю взаимопомощи:
SOS-оповещение соседей за 60 секунд, карта поиска, районное комьюнити, цифровой
паспорт питомца с QR, магазин адресников ручной работы. Маскот — корги Шуня —
живёт во всех ключевых сценариях, в том числе как анимированный помощник в углу.

Разрабатывается по ТЗ «Лапка помощи» (адаптивный веб-сайт + мобильное приложение).

## 🧰 Технологический стек

| Слой | Технология | Зачем |
|------|------------|-------|
| Фреймворк | **Next.js 15 (App Router) + TypeScript** | SSR, файловый роутинг 1:1 с картой сайта, Server Actions и API-роуты |
| База данных | **PostgreSQL + Prisma** (через docker-compose) | пользователи, питомцы, объявления, посты, заказы |
| Авторизация | **Сессии на cookie + scrypt** (`src/lib/auth.ts`) | без внешних зависимостей |
| Стили | **Tailwind CSS v4** | дизайн-токены палитры в CSS (`@theme`) |
| Анимации | **Framer Motion** + CSS | живой маскот, появления секций, count-up |
| Иконки / QR | **lucide-react** · **qrcode.react** | иконки и QR-паспорт |
| Карта | **Яндекс.Карты v3** (с фолбэком) | карта поиска по ключу `NEXT_PUBLIC_YANDEX_MAPS_KEY` |
| Тесты | **Vitest** (node-окружение) | юнит-тесты логики |
| Шрифты | **Comfortaa** + **Nunito** | округлые, тёплые, кириллица |

> **Пины под окружение (Node 20.8.1):** Next.js **15.5.19**, Vitest **2.1.9**, Prisma **5.22**.
> Обновишь Node до 22 LTS — поднимем версии.

## 🚀 Запуск

```bash
docker compose up -d        # PostgreSQL (порт 5433)
cp .env.example .env        # DATABASE_URL уже настроен на этот Postgres
npm install
npm run db:migrate          # применить миграции
npm run db:seed             # демо-данные (юзер anya / demo1234, питомцы, товары, посты, объявления)
npm run dev                 # http://localhost:3000 (или ближайший свободный порт)
```

Прочее: `npm run build` · `npm run lint` · `npm test` · `npm run db:studio`.
Демо-вход: телефон `+79991234567` или email `anya@example.ru`, пароль `demo1234`.
Приложение устанавливается как **PWA** на домашний экран iOS/Android.

## ⚠️ Заметки

- **БД — PostgreSQL** (docker-compose, том `lapka-pgdata`). Массивы (приметы, маршруты,
  характер) хранятся JSON-строками — переносимо. `npm run db:studio` для просмотра. Если после `git pull` Prisma ругается на расхождение миграций — `npx prisma migrate reset` (или снести том: `docker compose down -v`).
- **Маскот в углу** — анимированный на реальном арте (вырезан прозрачный фон в
  `tools/cut_poses.py`): дышит, покачивается, наклоняется к курсору, машет при наведении.
- **Уведомления и платежи** — заглушки: SOS создаёт объявление в БД (без push/Telegram),
  оформление заказа создаёт Order (без реальной оплаты).
- **Карта Яндекса** — по ключу `NEXT_PUBLIC_YANDEX_MAPS_KEY`; без него — список меток.
- `npm audit` — несколько умеренных предупреждений от транзитивных пакетов (build-time).
