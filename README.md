# 🐾 Лапка помощи

> Городское сообщество собачников Москвы для оперативного поиска потерявшихся собак.
> **Каждый хвост на учёт.**

«Лапка помощи» объединяет владельцев собак в единую городскую стаю взаимопомощи:
SOS-оповещение соседей за 60 секунд, карта поиска, районное комьюнити, цифровой
паспорт питомца с QR-кодом и магазин адресников ручной работы. Маскот — корги
Шуня — сопровождает пользователя во всех ключевых сценариях.

Проект разрабатывается по ТЗ «Лапка помощи» (адаптивный веб-сайт + мобильное
приложение iOS/Android).

## 🧰 Технологический стек

| Слой | Технология | Зачем |
|------|------------|-------|
| Фреймворк | **Next.js 15 (App Router) + TypeScript** | SSR публичных страниц-паспортов по QR и SEO, файловый роутинг 1:1 с картой сайта, API-роуты как бэкенд |
| Стили | **Tailwind CSS v4** | дизайн-токены палитры прямо в CSS (`@theme`) |
| Анимации | **Framer Motion** | живая Шуня, появления секций, count-up |
| Иконки | **lucide-react** | лёгкие SVG-иконки |
| QR | **qrcode.react** | QR-код цифрового паспорта питомца |
| Тесты | **Vitest** (node-окружение) | юнит-тесты логики (валидация, шаги мастера, навигация) |
| Шрифты | **Comfortaa** (заголовки) + **Nunito** (текст) | округлые, тёплые, с поддержкой кириллицы |

> **Пины под окружение.** На машине разработки Node **20.8.1**, поэтому зафиксированы
> совместимые версии: **Next.js 15.5.19** (Next 16 требует Node ≥ 20.9) и **Vitest 2.1.9**
> (Vitest 3 через rolldown требует `node:util.styleText` из Node ≥ 20.12). Обновишь
> Node до 20.12+/22 LTS — поднимем обе версии.

### Данные и интеграции (по дорожной карте)
- **PostgreSQL + Prisma** — основное хранилище (сейчас формы работают на UI-состоянии).
- **Яндекс.Карты API** — карта поиска и точки прогулок.
- **Telegram-бот** — дублирование SOS в районные чаты.
- **Нативное приложение** — Expo/React Native (сейчас веб — устанавливаемая PWA).

## 🚀 Запуск

```bash
npm install
npm run dev      # http://localhost:3000 (или ближайший свободный порт)
```

Сборка и проверка:

```bash
npm run build    # production-сборка
npm run start    # запуск собранного приложения
npm run lint     # ESLint
npm test         # Vitest — юнит-тесты логики
```

Приложение устанавливается как **PWA** (manifest + иконки) на домашний экран iOS/Android.

## ⚠️ Заметки

- Формы онбординга и мастера питомца пока работают на UI-состоянии (без бэкенда):
  SMS/почта не отправляются, данные не сохраняются — это следующий этап.
- Счётчик «найдено сегодня» считается на сервере детерминированно (без БД) — заглушка до реального агрегата.
- `npm audit` показывает 2 умеренных предупреждения от транзитивного `postcss`
  (XSS при обработке недоверенного CSS) — это инструмент сборки, в рантайме
  поверхности атаки нет.
