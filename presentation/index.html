⚙️ Технологии и надёжность
Современный стек, готовый к проду

🧱 Технологии

▹Next.js 15 (App Router, Server Actions) + TypeScript
▹Tailwind CSS v4 + Framer Motion, дизайн-система бренда
▹Prisma + PostgreSQL (Docker), выверенные миграции
▹Leaflet + OpenStreetMap — карта без платных ключей
▹web-push (VAPID), nodemailer, Telegram-бот
▹PWA — устанавливается как приложение; Docker-деплой

🛡️ Надёжность и безопасность

▹Удаление аккаунта по 152-ФЗ (право на забвение)
▹Пароли на scrypt, сессии в БД, верификация e-mail
▹Rate-limiting чувствительных эндпоинтов
▹Контакты — только с согласия владельца
▹26 автотестов + детерминированные verify-скрипты
▹Юридические страницы: политика и оферта
